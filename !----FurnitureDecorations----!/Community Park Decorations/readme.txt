Community Park Decorations for Alternative Textures - 1.x.x

Adds over 100 Park and Farmers' Market textures that can be applied to Vanilla catalog furniture items. Most items are from the Standard Furniture catalog (purchase from robin's shop), a few must be found in the 1.6 catalogs (Wizard catalog, Junimo Catalog, etc). 

::OPTIONAL ENHANCEMENTS::
For maximum decorating flexibility, consider adding a mod that allows bookcases to be placed outdoors.
I recommend "Place Furniture Outside" by glymr:
[https://www.nexusmods.com/stardewvalley/mods/21147]

:: REQUIREMENTS ::
* Alternative Textures

:: FEATURES ::
Includes textures for: 
* Benches
* Square tables (2 x 2)
* Wide Tables (3 x 2)
* Chairs and Stools
* Bookcases => Shrubs, Planters, Balloons
* Dressers => veggie planters and hedges (rotate to reveal more colors)
* End tables => plinths, crates, BBQs
* Small Tabletop items => Misc park accessories, food, gifts, backpacks
* Houseplants => trash cans and more decor items
* Floor Lamps => Park lamps
* Tall columns => Balloons
* Large Junimo Hut => Vendor stalls
* Tall paintings (1 x 3) => Fence panel, 
* Tree of the winter Star =>  Big shrubs, planters, Giant Crops
* Medium decor (2 x 2, like the low bookcases, Junimo Planter, Joja crate) => Park signs, miscellaneous decor
* Fences
* Flooring & Wallpaper
* Seasonal Paths
