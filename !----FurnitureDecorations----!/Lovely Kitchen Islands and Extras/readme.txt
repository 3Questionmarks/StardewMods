
* * *   LOVELY KITCHEN ISLANDS AND EXTRAS   * * *

Version 1.0.0
By Lulu Lovely (Nicole Balch)


= = = = = = = = = = = = = = = = = = = =


The Lovely Kitchen needed a Lovely Kitchen Island! Includes two sizes and many colors, plus a matching coffee machine, telephone, and freestanding kitchen cabinets.

You can also add the optional separate mod "Lovely Kitchen" for coordinating kitchens, with various cabinet, counter, handle, and appliance colors to choose from.


= = = = = = = = = = = = = = = = = = = =


* * *   REQUIREMENTS   * * *

SMAPI
Alternative Textures


= = = = = = = = = = = = = = = = = = = =


* * *   INSTRUCTIONS   * * *

- Install the latest versions of SMAPI and Alternative Textures.
- Download this mod, unzip it, and place the "[AT]Lovely Kitchen Islands and Extras" folder into your Stardew Valley Mods folder.
- Buy a Paint Bucket from Robin to select new colors and textures!


= = = = = = = = = = = = = = = = = = = =

18 colors with 3 countertop colors each
Also includes the kitchen cart design from Lovely Coffee Maker

*  TELEPHONE  *
Incorporate the telephone to look like part of your kitchen
18 colors with 3 countertop colors each


*  DRIED SUNFLOWERS  *
The large kitchen island has a vase of flowers on top. Use this to add a matching small or large version of these flowers elsewhere.
